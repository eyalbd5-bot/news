# חדשות אייל

אתר חדשות אישי: כדורגל, חדשות, AI וחדשנות. בעברית. סטטי, חינמי, מתעדכן לבד.
האפיון המלא: `אפיון.md`.

## מבנה

| נתיב | תפקיד |
|---|---|
| `index.html` `style.css` `app.js` | האתר. בלי בנייה, בלי תלויות |
| `config/sources.json` | התחומים, המקורות, הקבוצות והליגות. תחום חדש = בלוק חדש כאן |
| `pipeline/run.py` | ריצה אחת: שאיבה, שליפת כתבות, תיוג, איחוד כפילויות, תרגום, ניקוי, כתיבה |
| `data/index/<topic>.json` | הידיעות של כל תחום, 7 ימים, בלי גוף הכתבה |
| `data/body/<id>.json` | גוף הכתבה + התקציר העברי, נטען לפי דרישה |
| `data/meta.json` | דוח הריצה האחרונה (מצב כל מקור, ספירות, תרגום) |
| `.github/workflows/update.yml` | הרצה אוטומטית כל 30 דקות ב-GitHub Actions |
| `.env` | המפתח של Gemini. **לא עולה ל-GitHub** (ב-.gitignore) |

## הרצה מקומית

```bash
pip3 install -r requirements.txt
python3 pipeline/run.py
python3 -m http.server 8765
```
ואז לפתוח `http://localhost:8765`.

משתני סביבה אופציונליים: `MAX_EXTRACT` (ברירת מחדל 150 כתבות לריצה), `MAX_TRANSLATE_REQUESTS` (60 בקשות לריצה, 5 ידיעות בבקשה).

## איך הידיעה זורמת

1. `sources.py` קורא כל פיד (או את ה-API של 365scores) ומנרמל לידיעה אחידה. המזהה הוא גיבוב של הכתובת אחרי ניקוי פרמטרי מעקב, כך שאותה כתבה משני מקורות מתאחדת.
2. `extract.py` שולף את הכתבה המלאה ותמונת og:image כשחסרה (trafilatura).
3. `tags.py` מתייג כדורגל לפי קבוצות וליגות מהקונפיג.
4. `dedupe.py` מקבץ אותה ידיעה ממקורות שונים לפי דמיון כותרות, בחלון של 36 שעות.
5. `translate.py` שולח ידיעות זרות חדשות ל-Gemini (5 בבקשה): כותרת, תקציר קצר ותקציר מלא בעברית. ידיעה מתורגמת פעם אחת ונשמרת.
6. ידיעות ישנות מ-7 ימים נמחקות, האינדקסים נכתבים, ו-`meta.json` מתעדכן.
